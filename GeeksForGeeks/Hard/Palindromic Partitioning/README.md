<pre><span style="font-size: 14pt;"><strong><strong>Input: </strong></strong>s = "aaaa" <br><strong><strong>Output</strong></strong>: 0<br><strong><strong>Explanation:</strong></strong> The string is already a palindrome.</span></pre>
